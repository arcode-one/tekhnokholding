# Два блока на одном изображении

Превью: http://localhost:5173/prototypes/roof-story/index.html

Хиро и блок «Технохолдинг в цифрах» находятся внутри одного `.roof-story`. Единственная картинка покрывает весь контейнер; у секций нет собственных фоновых изображений. Затемнение усиливается плавно вниз, без границы между блоками.

Показатели перенесены из предоставленного изображения: 1 500 000+ м² кровель, 90% постоянных клиентов, 48 городов, 1000+ объектов. Новые численные утверждения не добавлены.

Слева заголовок раздела, справа главный показатель площади; под ним три остальных значения с тонкими разделителями. На телефоне главный показатель занимает всю ширину, остальные идут по двум колонкам.

Основные index.html, css/style.css и js/main.js не изменены. Резервная копия перед экспериментами: hero-before-focus.zip в папке визуализаций этого чата.
