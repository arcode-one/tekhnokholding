# Сравнение акцентов первого экрана

Открыть `http://localhost:5173/prototypes/hero-focus/index.html`.

- 1: «Цифры» — вертикальная композиция с отдельной цифрой стажа.
- 2: «Пара» — два достижения рядом.
- 3: «Плашка» — отдельный графитовый блок стажа.
- 4: «Было» — исходная композиция.

Клавиши 1–4 и стрелки переключают варианты, R возвращает выбранный вариант к начальному состоянию. Выбор сохраняется в URL.

Основные index.html, css/style.css и js/main.js при создании вариантов не менялись. Прототип использует нативный скролл, чтобы при частом пересоздании iframe не оставались фоновые обработчики сглаживания. Скролл основного сайта сохранён.
