# Технохолдинг

Статический сайт на HTML, CSS и JavaScript. Пакеты, сборщик и генерация страниц не нужны.

## Структура

```text
css/          стили: base, blocks, vendor, index.css
js/           скрипты: blocks, lib, vendor, index.js
images/       изображения, используемые на сайте
icons/        SVG, логотипы и спрайт
fonts/        локальные шрифты и лицензии
data/         данные карты и согласованный контент
docs/         PDF для скачивания
objects/      страницы отдельных объектов
*.html        главная и остальные разделы
serve.cjs     необязательный сервер для локального просмотра
```

## Запуск

Открой `index.html` через Live Server или выполни `node serve.cjs`.

Адрес: http://localhost:5173/. После изменения файлов обнови страницу. Другой порт: `node serve.cjs --port=5174`.

Для публикации нужны HTML и восемь папок из структуры выше. Node.js на хостинге не требуется. Через `file://` браузер ограничивает ES-модули и JSON, поэтому для просмотра нужен HTTP-сервер.

## Шрифт

Основной шрифт интерфейса: локальный Manrope Variable (200–800). Четыре крупных значения блока «Технохолдинг в цифрах» используют Jost Variable (100–900), жирность 400. Файлы WOFF2 и лицензии OFL находятся в `fonts/manrope/` и `fonts/jost/`, подключение через `css/base/fonts.css`. Семейства заданы переменными `--font-body` и `--font-figures` в `css/base/vars.css`. Внешних запросов к сервисам шрифтов нет.

Доступны все веса 100–900 в обычном и курсивном начертании, включая кириллицу. Основной текст использует 400, основные жирные заголовки 900, длинные подзаголовки 500, кнопки и названия карточек 500–600, активные состояния 700; отдельные крупные цифры сохраняют 300. Вес задаётся через `font-weight`, курсив через `font-style: italic`. Отдельные файлы для каждой жирности не нужны.

Общая гарнитура задаётся переменной `--font-body` в `css/base/vars.css`; `--font-display` и `--font-numbers` ссылаются на неё. На страницах заранее загружаются обычные кириллический и латинский наборы. Остальные языковые наборы и курсив браузер запрашивает только при использовании. Внешних запросов к сервисам шрифтов нет.

## GitHub Pages

Адрес сайта: https://arcode-one.github.io/tekhnokholding/.

В Settings → Pages используется Deploy from a branch: ветка `main`, папка `/ (root)`. После `git push origin main` GitHub публикует готовые файлы из корня репозитория. Сборка и папка `dist` не нужны; `.nojekyll` отключает обработку Jekyll.

Старые ссылки `/tekhnokholding/hero-test/` и `/tekhnokholding/hero-test/*.html` обрабатываются через `404.html`: браузер переходит на соответствующую страницу, сохраняя параметры и якорь. Неизвестные адреса остаются страницей 404. Внутренние ссылки должны быть относительными (`index.html`, `../index.html`), чтобы работать и в подпапке GitHub Pages.

## Редактирование

Взаимодействия и анимации написаны на обычном JavaScript и CSS: меню, ленты, фильтры, просмотр документов и скролл-эффекты. Плавность колеса на компьютере обеспечивает собственный `js/blocks/wheel-scroll.js`: путь уменьшен до 0,4 от исходного жеста, движение мягко затухает, а обратный жест сразу меняет направление. Используется настоящая позиция документа, без движущихся обёрток. Сенсорная прокрутка и внутренние списки нативные, якоря плавные через CSS. Lenis и прелоадер удалены. Общая круговая заливка текстовых и круглых кнопок в стиле October реализована в `button-fill.css` без JS и библиотек. Движение надписи находится в `pill.css`, текст в одном `span.pill__label` без дублирования; иконки неподвижны. Анимационные циклы работают только при необходимости; эффекты вне экрана приостанавливаются. Настройка уменьшенного движения учитывается.

Для интерактивной карты сохранена локальная MapLibre в `js/vendor/` и `css/vendor/`. Она загружается только при приближении к карте. Это единственная сторонняя библиотека интерфейса; удалять её без замены карты нельзя.

Миссия и таланты находятся на главной в блоке `#mission`. Старый адрес `mission.html` перенаправляет на этот блок, а якоря отдельных ценностей ведут на `values.html`.

«Служба качества» использует нативные анимации с собственной последовательностью в `quality.js` и `quality-motion.css`: заголовок, описание и100% в хиро; последовательные строки этапов; раскрытие галереи от большого кадра к малым; контакты футера. Все36 появлений однократные до перезагрузки, все7 фото имеют внутренний параллакс. Для кадров с людьми амплитуда подобрана отдельно. Общий жизненный цикл появлений вынесен в `js/lib/scroll-reveal.js`, параллакс в `js/lib/photo-parallax.js`. Аккордеон и просмотрщик фото работают независимо, фокус/нажатие мгновенно показывают соответствующий элемент. Старые `company-reveal`, `story-photo` и `data-footer-motion` отключены только на quality.html.

Дизайн-система и справочник параметров: [DESIGN-SYSTEM.md](DESIGN-SYSTEM.md). В нём описаны цвета, размеры и варианты заголовков, контейнеры, адаптив, компоненты, анимации и файлы для их изменения.

- Текст и разметка находятся в HTML. Хедер и футер повторяются на страницах.
- При изменении объектов синхронизируй HTML и `data/projects.json`.
- CSS блока: `css/blocks/name.css`, адаптив: `name.media.css`. JS блока: `js/blocks/name.js`.
- Изображения и варианты размеров готовятся отдельно и подключаются через `src` и `srcset`.
