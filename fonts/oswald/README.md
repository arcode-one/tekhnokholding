# Oswald

Variable font used only for the object collection heading and result count.
Source: https://github.com/google/fonts/tree/main/ofl/oswald
Original file: `Oswald[wght].ttf`, renamed locally to `Oswald-Variable.ttf`.
License: SIL Open Font License 1.1, included in `OFL.txt`.
Self-hosted; the shared header, wordmark and body text retain their existing fonts.
