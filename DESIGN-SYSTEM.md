# Дизайн-система Технохолдинг

Актуально на 3 ноября 2026 года. Справочник описывает существующую реализацию: параметры, их назначение, область действия и файлы для редактирования. Сам документ не подключается к сайту и не меняет оформление.

| Файл или папка | Что отвечает за оформление |
| --- | --- |

| `css/blocks/имя.css` | Основной вид конкретного блока |
| `css/blocks/имя.media.css` | Изменения этого блока на других размерах экрана |
| [js/index.js](js/index.js) | Подключение поведения по `data-*` атрибутам |
| `js/blocks/имя.js` | Анимация, интерактивность и вычисляемые размеры конкретного блока |
| `*.html`, `objects/*.html` | Тексты, структура, ссылки, пути к изображениям и варианты `srcset` |

Сайт статический, без сборщика. Хедер и футер повторяются в HTML страниц. Общий CSS меняет их вид сразу везде, а текст или разметку нужно менять во всех нужных копиях.

Важен каскад: базовые стили идут первыми, примитивы кнопок перед блоками, затем стили блоков с их адаптивом. `home-heading.css` и его адаптив подключены в самом конце. Поэтому раннее правило `.company-heading h2` не определяет окончательный вид заголовков главной.

## 3. Типографика

### Гарнитура и смысл параметров

Основной шрифт интерфейса: локальный Manrope Variable, веса `200–800`, прямое начертание, кириллица и латиница. `--font-body`, `--font-display`, `--font-numbers` указывают на Manrope. Только четыре крупных значения второго блока (`1 500 000+`, `1000+`, `90%`, `48`) используют Jost Variable через `--font-figures`, жирность `400`. Jost поддерживает веса `100–900`. Файлы WOFF2 и лицензии OFL лежат в `fonts/manrope/` и `fonts/jost/`, внешних шрифтовых запросов нет. Новые применения Jost вне второго блока согласовываются отдельно.

| Свойство | За что отвечает | Пример |
| --- | --- | --- |
| `font-size` | Размер букв | `60px` у основного заголовка блока |
| `font-weight` | Жирность | `900` основные заголовки, `500` длинные подзаголовки |
| `line-height` | Высота строки относительно размера шрифта | `1` при 60px даёт строку 60px; `1.35` при 32px даёт 43.2px |
| `letter-spacing` | Межбуквенный интервал | `-0.03em` слегка уплотняет крупный заголовок |
| `text-transform` | Регистр при отображении | `uppercase` показывает капс без переписывания текста в HTML |
| `max-width: 42ch` | Ограничение длины строки | `ch` зависит от метрики шрифта, а не от точного числа букв |
| `display: block` у второго `span` | Смысловой перенос строки | Вторая часть заголовка начинается с новой строки |

`clamp(минимум, гибкое значение, максимум)` ограничивает размер снизу и сверху. Например, `clamp(24px, 1.9vw, 34px)` даёт 27.36px при ширине 1440px и 34px при 1920px. `1vw` равен 1% ширины окна.

### Пример двухцветного заголовка главной

```html
<h2 class="home-heading" id="company-map-title">
  Наш опыт <span class="home-heading__muted">на карте</span>
</h2>
```

Сейчас `.home-heading` оформляется внутри заданных контейнеров главной и каталога, а не в любом месте сайта. На главной используется `text-wrap: nowrap`: если заменить текст на более длинный, нужно проверить каждую строку на узком экране. У миссии применяется `text-wrap: balance`, а названия длинных сцен могут переноситься естественно.

У сайта нет единого узкого центрированного `max-width` контейнера. Основные края задаются `--pad`; текстовые колонки могут иметь собственную максимальную ширину. Контент политики занимает всю ширину общего контейнера, без прежнего ограничения 1560px.

Для простого нового блока с общими полями подходит `padding-inline: var(--pad)`. Если поля уже стоят у родителя, не добавляй их повторно дочернему элементу.

## 5. Компоненты и состояния

### Круглая кнопка с иконкой `.icon-btn`

Источник: [icon-btn.css](css/blocks/icon-btn.css), [адаптив](css/blocks/icon-btn.media.css).

| Параметр | Значение | Что меняет |
| --- | --- | --- |
| Размер | `48×48px`, до 767px `44×44px` | Размер кнопки и области нажатия |
| Иконка | `26×26px`, до 767px `24×24px` | Размер SVG; стрелки объектов имеют локальные уточнения |
| Скругление | `50%` | Круглая форма |
| Исходный фон | Прозрачный, обводка `1px` | Белый текст/граница на тёмном, графитовый на светлом |
| Hover | Инверсия цветов, `0.35s ease` | Только фон/цвет/граница, без перелистывания иконки |
| Цвет hover | `--button-hover-text` | Графитовый на белом или белый на графитовом |
| Disabled | `opacity: 0.35` | Недоступное состояние |

Применяется к стрелкам, мессенджерам и кнопкам закрытия. Общие состояния находятся в `buttons.css`; фон секции задаёт контекст. Бургер исключён из общей рамки/заливки: прозрачная кнопка без обводки, только линии и их собственная анимация; keyboard focus остаётся видимым.

### Текстовая кнопка `.pill`

Источник: [pill.css](css/blocks/pill.css), [адаптив](css/blocks/pill.media.css).

Базовая высота `52px`, горизонтальный padding `28px`, радиус `26px`, текст `17px/500`, прозрачный фон, граница `1px` по светлому/тёмному контексту. На мобильном высота `50px`, padding `12px`, текст `15px`.

Обычный hover/focus: нейтральная инверсия за `0.35s ease`. `.pill--calypso` повторяет исходный ButtonCalypso October: круглая заливка `0.4s cubic-bezier(.1,0,.3,1)`, завершающий слой `0.05s` после `0.4s`; одна надпись и два keyframes по `0.3s`, второй после `0.3s`, со scaleY(2). Две копии текста не используются. На reduced-motion, coarse-pointer, disabled и активных фильтрах движения нет. До360px padding8px/текст13px.

## 6. Фото, хиро и футер

### Общие принципы изображений

`object-fit: cover` заполняет кадр с обрезкой краёв, `contain` показывает изображение целиком с возможными свободными полями. `object-position` выбирает точку кадрирования, но не передвигает сам блок. Для растров используются WebP, варианты размеров подключаются через `srcset`, важное изображение хиро имеет `fetchpriority="high"`.

Контактное значение `clamp(18px, 1.65vw, 26px)`, до 1100px `22px`; иконки `24px`, наследуют белый/светло-серый цвет ссылки; подписи `10px/500`, капс, tracking `0.08em`. Hover контактов `#D9DADF` за `0.35s ease`, без подчёркивания. Ссылка на политику отдельно сохраняет подчёркивание.

Футер одинаково работает на главной и миссии. Текст и контакты двигаются в обычном потоке страницы. Только фоновая фотография имеет параллакс; отдельного sticky-наезда всего футера нет.

## 7. Анимации и прокрутка

### Общие кривые и длительности

| Параметр | Значение | Назначение |
| --- | --- | --- |
| `--ease-out` | `cubic-bezier(0.2, 0.8, 0.2, 1)` | Мягкое торможение, в том числе фото карточек и док |
| `--ease-in-out` | `cubic-bezier(0.65, 0, 0.25, 1)` | Плавное начало и завершение, раскрытие фото/движение шапки |
| Hover цвета | Обычно `0.2s ease` | Ссылки и элементы управления |
| Hover фото карточки | `0.4s var(--ease-out)` | Подъём и увеличение фотографии |
| Переключение годов | `top 0.45s cubic-bezier(0.22, 1, 0.36, 1)` | Перемещение в барабане |
| Раскрытие общего фото | `clip-path 0.6s var(--ease-in-out)` | `.company-reveal--visible` |

Для скролл-анимаций длительность часто определяется расстоянием прокрутки, а не секундами. Изменение общего easing не меняет все числовые коэффициенты в JS.

### Плавная прокрутка

Источник: [smooth-scroll.js](js/blocks/smooth-scroll.js), локальный Lenis.

| Параметр | Значение | Эффект |
| --- | --- | --- |
| `wheelMultiplier` | `0.4` | Меньше расстояние за жест колеса |
| `duration` | `1.2` секунды | Длительность сглаживания |
| `easing` | `1 - (1 - progress) ** 3` | Кубическое затухание |
| `lerp` | `0` | Используется режим duration, без отдельного lerp-затухания |
| `maxPendingScroll` | `innerHeight * 0.5` | Ограничивает накопленную инерцию половиной экрана |
| Разворот | Сразу от текущей позиции | Обратный жест не ждёт исчерпания старой инерции |
| `syncTouch` | `false` | Сенсорная прокрутка нативная |
| `anchors` | `true` | Поддержка якорных переходов |

`PixelAlignedLenis` округляет scroll до физических пикселей с учётом `devicePixelRatio`. Не убирать это при настройке плавности: оно уменьшает дробное смещение текста. `[data-lenis-prevent]`, меню и select сохраняют нативную обработку. При `prefers-reduced-motion: reduce` Lenis не создаётся.

### Миссия: раскрытие отдельно от движения

Источник: [mission.js](js/blocks/mission.js), [mission.css](css/blocks/mission.css).

| Эффект | Параметр | Поведение |
| --- | --- | --- |
| Раскрытие внутренних фотографий | Сохранённый максимум прогресса | Один раз вперёд до перезагрузки, при обратном скролле не закрывается |
| Параллакс внутри рамок | До `±10%` высоты рамки desktop, `±6%` mobile | Следует скроллу в обе стороны |
| Запас фото за кадром | `inset-top: -14%`, высота `128%` | Перекрывает края при параллаксе |
| Карточка-мост | `(p - 0.5) * 64px`, mobile `24px` | Диапазон `-32…32px`, mobile `-12…12px`, в обе стороны |
| Декоративные углы | Прогресс текущей прокрутки | Подъём и изменение геометрии обратимы |
| Дополнительный сдвиг result-сцены | `36px`, mobile `16px` | Следует текущему прогрессу, отдельно от открытой маски |

Геометрия считается через `offsetTop/offsetHeight`, без обратной зависимости от уже применённых transform. Текст сцен остаётся обычным слоем без масок и сдвигов. У `.mission-purpose > :not(.mission-corner)` сохраняются `position: relative; z-index: 1`: это защищает заголовок от перекрытия декоративным углом.

### Другие фото и футер

`company-reveal.js` раскрывает только изображения при первом появлении, затем отключает свой IntersectionObserver. `story-photo.js` даёт обратимый сдвиг фото до `±2.4%` и `scale(1.055)` для `[data-story-photo]`.

`roof-background.js` двигает фон с коэффициентом `0.3` от пройденной прокрутки. `SPLIT_DISTANCE: 0.6` определяет расстояние в долях высоты экрана для раскрытия композиции главного хиро.

`site-footer.js` включает параллакс фото от 768px: максимальное смещение равно `imageHeight * 0.5`, оно уменьшается до нуля при входе футера. На мобильном и при reduced motion transform фотографии очищается. Контактный текст отдельно не трансформируется.

### Reduced motion

При `prefers-reduced-motion: reduce` отключаются или упрощаются плавная прокрутка, параллаксы, раскрытия и переходы поддерживающих это блоков. Фото миссии открываются полностью. Для новых эффектов нужно сохранять тот же принцип и доступность содержимого без анимации. У отдельных существующих hover-состояний reduced motion убирает переход, но конечное состояние может сохраняться; это не глобальное удаление всех CSS transform.

## 8. Слои, фокус и доступность

| Элемент | Фактический слой | Источник |
| --- | --- | --- |
| Полноэкранное меню | `15` | `menu.css` |
| Шапка | `20` | `header.css` |
| Док | `30` | `dock.css` |
| Прелоадер | `--layer-preloader: 100` | `vars.css`, `preloader.css` |
| Пользовательский скроллбар | `--layer-scrollbar: 10000` | `vars.css`, `site-scrollbar.css` |
| Native dialog | Верхний слой браузера при `showModal()` | `company-lightbox.js` |

`--layer-header: 50` объявлен, но хедер сейчас использует собственный `z-index: 20`. Изменение этой переменной само по себе не поднимет шапку. Значения z-index сравниваются внутри контекстов наложения, а не как одна глобальная очередь для всех детей.

Базовый `:focus-visible`: контур `2px solid currentcolor`, offset `3px`. Крошки, карточки и другие компоненты имеют свои уточнения. Hover включается для `(hover: hover) and (pointer: fine)`, а клавиатурный focus задаётся отдельно. Для кнопки-иконки нужен понятный `aria-label` или доступный текст.

В политике активная ссылка содержания имеет `aria-current="location"` и вес `700`; остальные остаются обычными. [privacy-toc.js](js/blocks/privacy-toc.js) обновляет состояние при прокрутке, переходах и resize, а не только по клику. До 1100px содержание переходит над текстом, до 767px скрыто.

## 9. Логотипы и фавиконки

Логотипы и SVG лежат в `icons/`. Для фото-хиро используется светлый вариант, например `logo-light-compact.svg`. Фавиконка содержит только эмблему, без надписи:

- `icons/favicon.svg`;
- `icons/favicon.ico` с размерами 48/32/16px;
- `icons/apple-touch-icon.png`, 180px.

На новых страницах подключаются все три. Пути относительные: в корне `icons/...`, внутри `objects/` путь `../icons/...`. Аналогично ссылки на страницы должны работать в подпапке GitHub Pages.

## 10. Как менять оформление

| Задача | Что редактировать | Что проверить после изменения |
| --- | --- | --- |
| Изменить нейтральные акценты | `palette.css`, `button-theme.css` | Навигация, выделение, карточки, карта; золото только в хиро, логотип оригинальный |
| Изменить только hover кнопок | `--button-hover-bg`, `--button-hover-text`, `--button-hover-border` | Светлый/тёмный контекст, hover/focus; бургер без рамки |
| Изменить поля всех контейнеров | `--pad` и его mobile-значение | Нет двойных полей или вылезших стрелок |
| Изменить высоту шапки | `--header-h` | Крошки, начало main, sticky-элементы, хиро |
| Изменить основные H2 главной | `home-heading.css` и `.media.css` | Все пять заголовков и H1 каталога, особенно длинные строки |
| Изменить заголовки миссии | `mission.css` и `.media.css` | H1, большие H2 и отдельные маленькие названия сцен |
| Уменьшить длинные названия сцен | `.mission-story .mission-scene__heading` | Одноцветность, обычный регистр, 32/20px |
| Изменить приглашение футера | Вид: `site-footer.css`; текст: HTML всех футеров | Три строки, один цвет, совпадение страниц |
| Заменить фото качества | `quality.html`: source/src/srcset/OG; `quality-page(.media).css`: object-position | Люди в кадре, читаемость текста, обе ориентации |
| Заменить хиро миссии | `mission.html`: src/srcset/OG; `mission.css`: `.mission-hero__photo::after` | Текущее фото `images/mission/mission-light-rooftop-v1.webp`, светлая кровля и город. Верх локально затемнён для навигации, слева мягкая подложка под H1; вторая строка `--color-mist`. Не затемнять весь кадр |
| Усилить параллакс миссии | Коэффициенты `0.1/0.06` в `mission.js` | Достаточен ли запас фото за рамкой, скролл вверх и вниз |
| Изменить автоскорость ленты | Целевая скорость `32` в `projects-section.js` | Пауза, drag, цикл и reduced motion |
| Уменьшить путь за жест колеса | `wheelMultiplier` в `smooth-scroll.js` | Сохранены плавность и мгновенный разворот |

После правок основных стилей достаточно открыть затронутые страницы на ширинах 1920, 1440, 768, 390 и 320px; для границ адаптива также проверить нужный breakpoint. Проверить отсутствие горизонтального переполнения, длинные заголовки, hover/focus, reduced motion и скролл в обе стороны. Локальный просмотр: `node serve.cjs`, адрес `http://localhost:5173/`.

При изменении решения обновляй этот документ вместе с CSS/JS. Числа здесь являются снимком текущего кода, а не дополнительным файлом настроек. В коде пока нет общих токенов размера заголовков, вертикального ритма всех секций или единой шкалы радиусов: эти значения редактируются в перечисленных блоках.
